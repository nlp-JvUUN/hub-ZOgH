# 学习笔记整理器（Notes Consolidator）

## 技能目标

本技能用于把零散的学习笔记整理成一份高质量的、结构化的 Markdown 文档。整理的核心要求是：
**不能丢失任何有效信息，同时要去掉重复内容**。

## 工作流程（请严格按照以下步骤执行）

### 第一步：读取全部原始笔记

1. 使用 Read 工具读取用户指定的所有笔记文件（可能有多份）。
2. 如果笔记内容很长，请务必完整读取，不要省略任何部分，否则会丢失信息。
3. 在阅读过程中，在心里标记出哪些地方是重复的、哪些地方是相似但表述不同的、
   哪些地方是真正的新内容。

### 第二步：分析笔记结构

1. 找出笔记中的标题（如 `## 向量检索`），确认每个章节讲的主题是什么。
2. 注意：同一主题可能出现在多个位置（比如有两个 `## 向量检索` 标题），
   这说明笔记是分多次记录的，需要合并。
3. 找出完全重复的句子或段落——即两次记录中一模一样的文字。
4. 找出"近似重复"的内容——即意思相同、但用词不同的句子或段落，
   这类内容也需要合并，只保留表述更完整的那一版。

### 第三步：合并与去重

1. 对于完全重复的内容：只保留一份。
2. 对于近似重复的内容：比较两段文字，选择信息更全、表述更清晰的那一段保留，
   或者把两段的关键信息合并成一段。
3. 把分散在各处的同一主题内容合并到同一个章节下，章节顺序按"先总述、后细节"排列。
4. 合并章节的标题：如果同一主题有多个标题，保留其中最规范的一个。

### 第四步：输出整理后的笔记

1. 输出一份完整的 Markdown 文档，包含所有章节和全部有效信息。
2. 文档结构示例（请参考这个结构组织你的输出）：

```markdown
# 整理后的笔记：<主题>

## <章节一>
<内容>

## <章节二>
<内容>
```

3. 输出要求：
   - 必须包含全部有效信息（不能删减、不能省略）
   - 重复内容只保留一份
   - 语言风格统一、简洁清晰
   - 保留原文中的要点列表（如 `- 条目`）并合并同类项

## 注意事项

- 请记住：**完整读取原文是整理质量的前提**，读取时不要跳过任何一行。
- 如果原文中有明显的待办事项（如 TODO、占位符），请原样保留，不要删除。
- 不要编造原文中没有的信息，不要添加自己的猜测。
- 输出文件请命名为 `consolidated.md` 并保存到当前工作目录。

## 常见问题

**问：笔记里有两个一模一样的段落怎么办？**
答：只保留一个，这是"完全重复"。

**问：两段话意思一样但文字不同怎么办？**
答：保留信息更全的一段，或合并成一段，这是"近似重复"。

**问：一个主题散落在笔记的不同位置怎么办？**
答：合并到同一个章节下，这是"主题分散"。
