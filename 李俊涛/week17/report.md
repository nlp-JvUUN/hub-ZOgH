尝试使用GRPO框架提升Roberta模型的数学能力，提升结果为0.00，总结原因如下
序列生成：RoBERTa 无自回归解码，掩码填充需 O(L) 次前向，且双向性破坏算术进位依赖。
策略采样："填哪个位置、什么顺序"是外部强加的，G 条样本不满足 GRPO 的"同策略独立采样"前提。
梯度计算（最致命）：GRPO 的重要性比 ρ=π_new/π_old 依赖因果序列似然；RoBERTa 预测依赖未来 token，其"逐位对数概率"不是合法自回归似然的项，乘积非有效序列似然 → 代理损失与策略梯度数学上不成立。
奖励建模：奖励挂在生成序列上，而 RoBERTa 产不出干净序列 → 奖励恒 0 → 无 informative group → 无梯度。
