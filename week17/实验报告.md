# 实验：基于 GRPO 的强化学习提升模型做数学题能力

## 摘要

本实验使用 Group Relative Policy Optimization（GRPO）对 Qwen 系列 0.5B 指令模型进行算术题强化学习。实验程序化生成六档加减乘法题，在每个题目上采样 8 个回答，以答案正确性和输出格式构造可验证奖励。结果表明，经过 200 步 GRPO 后，六档题目的宏平均 greedy 正确率由 **49.67% 提升到 83.33%**，提高 **33.66 个百分点**；`<answer>` 格式遵循率也从接近 0 提升至 82%～100%。实验说明：无需人工偏好标注或独立价值网络，仅依靠规则验证器提供的奖励，GRPO 就能明显增强小模型的基础数学能力。

## 1. 实验目的

1. 理解 GRPO 的组内相对优势计算方法及其与 PPO 的区别。
2. 掌握可验证奖励在数学推理强化学习中的用法。
3. 实现“基线评估—GRPO 训练—训练后评估—结果分析”的完整流程。
4. 分析选题难度、组内采样和奖励塑形对训练效果的影响。

## 2. GRPO 原理

对同一道题目（prompt）从当前策略中采样一组回答 $o_1,\ldots,o_G$，通过规则奖励函数得到 $r_1,\ldots,r_G$。GRPO 不训练额外的价值网络，而是用组内奖励标准化得到相对优势：

$$
A_i=\frac{r_i-\operatorname{mean}(r_1,\ldots,r_G)}{\operatorname{std}(r_1,\ldots,r_G)+\epsilon}.
$$

再用类似 PPO 的 clipped surrogate objective 更新策略：

$$
J(\theta)=\mathbb{E}\left[\min\left(\rho_iA_i,\operatorname{clip}(\rho_i,1-\varepsilon,1+\varepsilon)A_i\right)\right]
-\beta D_{KL}(\pi_\theta\Vert\pi_{ref}),
$$

其中 $\rho_i=\pi_\theta(o_i|q)/\pi_{old}(o_i|q)$。本实验设 `epsilon=0.2`，并为节省显存设 `beta=0`。

GRPO 的关键是**同组回答需要有好有坏**。若一道题的 8 个回答全部正确或全部错误，组内标准差为零，优势也接近零，无法产生有效的相对学习信号。因此训练集重点采用基线中 informative group rate 较高的 L2、L3 和 L5。

## 3. 实验设计

### 3.1 模型与环境

- 基座模型：Qwen2/Qwen2.5 0.5B Instruct（代码默认 `Qwen/Qwen2.5-0.5B-Instruct`，也支持本地路径）
- 框架：PyTorch、Transformers、TRL、Datasets、PEFT
- 精度：BF16
- 推荐硬件：8GB 及以上 NVIDIA GPU

### 3.2 数据集

数据由 `src/math_utils.py` 在线生成，不依赖外部数据集，共六档：

| 难度 | 题型 | 是否用于训练 |
|---|---|---|
| L1 | 个位数加法 | 否，用于简单题泛化 |
| L2 | 两位数加减 | 是，25% |
| L3 | 三位数加减 | 是，50% |
| L4 | 一位数乘法 | 否，用于题型泛化 |
| L5 | 两位数乘一位数 | 是，25% |
| L6 | 两位数乘两位数 | 否，用于困难题泛化 |

模型被要求只输出 `<answer>整数</answer>`。训练题和评估题均由固定随机种子生成，保证可复现。

### 3.3 奖励函数

总奖励是两个分量之和：

$$R=R_{correct}+R_{format}.$$

- `reward_correct`：最后解析出的数字等于标准答案，奖励 1.0。
- `reward_format`：包含合法的 `<answer>...</answer>` 标签，奖励 0.2。

正确性采用宽松解析，是为了防止训练初期模型不会标签格式，从而导致所有回答的正确奖励均为零；格式奖励单独促使输出逐步规范化。

### 3.4 主要超参数

| 参数 | 数值 |
|---|---:|
| 训练步数 | 200 |
| 每题组内采样数 G | 8 |
| 温度 | 1.0 |
| 学习率 | 2e-6（全量） |
| LoRA 学习率 | 2e-4 |
| GRPO clip epsilon | 0.2 |
| KL 系数 beta | 0 |
| 最大补全长度 | 64 tokens |
| 训练集规模 | 1000 prompts |

## 4. 实验步骤

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 训练前基线评估
python src/evaluate.py --model Qwen/Qwen2.5-0.5B-Instruct \
  --output outputs/baseline_new.json

# 3. GRPO 训练
python src/train_grpo.py --model Qwen/Qwen2.5-0.5B-Instruct \
  --output-dir outputs/grpo_model

# 显存不足时可使用 LoRA
python src/train_grpo.py --model Qwen/Qwen2.5-0.5B-Instruct \
  --lora --output-dir outputs/grpo_model

# 4. 训练后评估
python src/evaluate.py --model outputs/grpo_model \
  --output outputs/grpo_new.json

# 5. 分析随作业附带的实验结果并生成图表
python src/analyze_results.py
```

Windows 也可以直接运行 `run_experiment.bat`。若模型已下载到本地，请把 `--model` 参数换成本地模型目录。

## 5. 实验结果

随作业提供了实际运行结果：`outputs/baseline_results.json`、`outputs/grpo_results.json` 和 `outputs/train_log.json`。测试集每个难度 50 道题，训练前后使用相同随机种子和题目。

| 难度 | 基线正确率 | GRPO 后正确率 | 绝对提升 | GRPO 后格式率 |
|---|---:|---:|---:|---:|
| L1 个位数加法 | 98% | 100% | +2% | 96% |
| L2 两位数加减 | 76% | 98% | +22% | 100% |
| L3 三位数加减 | 40% | 90% | +50% | 96% |
| L4 一位数乘法 | 56% | 100% | +44% | 82% |
| L5 两位数乘一位数 | 20% | 88% | +68% | 98% |
| L6 两位数乘两位数 | 8% | 24% | +16% | 98% |
| **宏平均** | **49.67%** | **83.33%** | **+33.66%** | **95.00%** |

训练集内的 L2、L3、L5 平均正确率由 45.33% 上升到 92.00%；未直接训练的 L1、L4、L6 也由 54.00% 上升到 74.67%，说明模型获得了一定的跨难度和跨题型泛化能力。

典型输出变化：

```text
题目：902 - 848
训练前：154
训练后：<answer>54</answer>

题目：28 × 8
训练前：112
训练后：<answer>224</answer>
```

## 6. 结果分析

1. **GRPO 显著提升中等难度题。** L3 提升 50 个百分点，L5 提升 68 个百分点。这些级别的基线采样既有正确答案也有错误答案，能提供较密集的相对优势信号。
2. **格式奖励效果明显。** 基线模型通常只输出数字，强化学习后六档格式率均达到 82% 以上，说明即使 0.2 的小奖励也能稳定塑造输出行为。
3. **存在泛化。** 未直接加入训练的 L4 从 56% 达到 100%，说明在加减法和两位数乘一位数上学习到的行为可迁移到简单乘法。
4. **过难题提升有限。** L6 从 8% 提高到 24%，但仍明显低于其他级别。基线对该难度大多数采样都失败，组内奖励方差较小；要继续提升，应逐渐将 L6 引入课程学习，而不是一开始大量加入。
5. **pass@k 与 greedy 指标作用不同。** pass@8 衡量模型是否“有概率答对”，可帮助判断题目能否为 GRPO 提供学习信号；greedy 正确率则更接近部署时的稳定能力。

## 7. 消融实验建议

可进一步进行以下对照：

- 去掉 `reward_format`，观察正确率和格式率变化。
- 将 `num_generations` 从 8 改为 4，对比采样成本和学习效果。
- 比较全参数训练与 LoRA 的显存、速度和最终准确率。
- 令 `beta>0` 加入参考模型 KL 约束，观察能力提升与策略漂移的权衡。
- 使用课程学习：当 L3/L5 正确率达到阈值后逐步加入 L6。

## 8. 结论

本实验完成了一个可复现的 GRPO 数学强化学习系统。基于确定性答案验证器的复合奖励，在 200 个训练步内把小模型六档算术题的宏平均正确率从 49.67% 提高到 83.33%，同时使输出格式趋于统一。结果验证了 GRPO 在可验证数学任务上的有效性，也说明训练题应优先选择“模型偶尔能够答对但尚未完全掌握”的难度区间。其局限是题目集中于基础整数运算，尚不能代表复杂数学推理；后续可以扩展到方程、应用题和带推理过程的奖励设计。
