## 3. 方法：GRPO 原理

GRPO 与 PPO 的核心差异在于 **advantage（优势）的来源**：

- PPO 需要**价值网络**（Critic）估计 baseline，并加载**参考模型**做 KL 约束。
- GRPO 去掉价值网络：对**同一个 prompt 采样 K 条补全**，用这 K 条奖励的**组内均值/标准差归一化**得到 advantage：

```
advantage_i = (r_i - mean(r_1..r_K)) / std(r_1..r_K)
```

本项目进一步把 `beta=0`（不加载参考模型，省 ~1GB 显存）。代价是：**全对或全错的组
advantage 全为 0，不产生梯度**。因此选题难度是 GRPO 工程的核心——本项目用
**informative group rate**（组内 `0 < 正确数 < K` 的比例）作为可学习性指标。

**复合奖励**（本消融实验的对象）：

```python
reward = reward_correct(1.0)   # 正确分：宽松解析，最后一个数字对即得分
       + reward_format(w)      # 格式分：输出含 <answer>N</answer> 得 w 分
```

正确分用**宽松解析**（无标签时取输出最后一个数字），是为了避免格式冷启动时正确信号也被
格式失败清零，导致组内 advantage 全 0、训练无法启动。

## 4. 实验设计

### 4.1 任务：6 级难度算术题

程序化生成，难度从「个位数加法」到「两位数×两位数」，每级 50 题评估（greedy + 8 次采样）。

### 4.2 基线摸底与难度选题

先用 `probe_baseline.py` 摸底 Qwen2.5-0.5B 在各难度的表现（seed=42）：

| 难度 | greedy 正确率 | 格式率 | loose pass@8 | informative 组比例 | 选题 |
|------|:---:|:---:|:---:|:---:|:---:|
| L1 个位数加法 | 0.90 | 0.48 | 1.00 | 0.48 | 太易，泛化 |
| L2 两位数加减 | 0.82 | 0.46 | 0.96 | 0.52 | **保底（20%）** |
| L3 三位数加减 | 0.80 | 0.68 | 0.96 | **0.68** | **主训（30%）** |
| L4 表内乘法 | 0.98 | 0.52 | 1.00 | 0.42 | 太易，泛化 |
| L5 两位×一位 | 0.92 | 0.60 | 0.98 | 0.56 | 近天花板，泛化 |
| L6 两位×两位 | 0.44 | 0.52 | 0.76 | **0.68** | **主训（50%）** |

> **关键发现**：Qwen2.5-0.5B 明显强于课程参考所用的 Qwen2-0.5B（参考里 L3/L5/L6 greedy 分别为
> 0.40/0.20/0.08），原「主训」的 L5 已接近天花板，原「能力边界」的 L6 反而成了新的甜区。
> 因此本实验**按 informative group rate 重新选题**：训练集 = L6(50%) + L3(30%) + L2(20%)，
> L1/L4/L5 留作**泛化评估**（回答「没训过的难度会不会也提升」）。

### 4.3 消融实验：格式分权重 w 三方对照

| 变体 | 格式分权重 | 假设（Hypothesis） |
|------|:---:|------|
| **w=0** | 0（删掉格式奖励，只给正确分） | 格式率停在基线水平（~0.5），证明「RL 只优化被奖励的行为」 |
| **w=0.2** | 0.2（基线） | 格式与正确性解耦协同，正确率稳步爬坡 |
| **w=1.0** | 1.0（格式与正确同权） | 格式秒收敛，但正确率爬坡被格式信号竞争拖慢 |

### 4.4 GRPO 关键配置

| 配置 | 值 | 说明 |
|------|----|------|
| `num_generations` (K) | 8 | 组内采样数，与基线摸底 pass@8 一致 |
| `beta` | 0.0 | 不加载参考模型，省显存 |
| `epsilon` | 0.2 | PPO-clip 裁剪范围 |
| `temperature` | 1.0 | 采样温度，保证组内多样性（GRPO 训练燃料） |
| 批次 | 8 completions × 累积 4 | 每步 = 4 prompt × 8 采样 = 32 条补全 |
| 学习率 | 2e-6 | 全量微调典型量级 |
| 步数 | 200 | 训练集 1000 题，约 5~6 分钟 |

## 6. 分析与结论

### 6.1 GRPO 有效提升数学能力，且能力泛化到未训练难度

- **训练集内**：L6（两位×两位）正确率 **0.44 → 0.60~0.62（+18pp）**，L3（三位加减）**0.80 → 0.92~0.94**。
- **未训练难度也在涨**：L1/L4/L5 全部到 0.96~1.00，说明 RL 强化的是「做对算术」的内部回路，而非背题。
- 印证了教科书结论：**RL 在模型能力边界内重排概率分布**（Qwen2.5 的 L6 仍在边界内，所以能学会）。

### 6.2 意外发现：格式率在三组都到 1.0，包括 w=0 —— 假设被证伪

原假设「w=0 只给正确分 → 格式率停在基线（~0.5）」**被证伪**：w=0 的格式率同样升到 1.00。

**机制解释（最可能的机制：奖励泄漏 / 代理奖励纠缠）**：Qwen2.5 的「格式遵循」和「正确性」在其预训练策略里
是**耦合**的——它「会做」时倾向于按指令输出 `<answer>N</answer>`，「不会做」时才输出裸数字。正确分虽然用宽松
解析（只看最后一个数字，与格式无关），但它奖励的是「正确的整段输出」，而这些输出在 Qwen2.5 的先验里
**绝大多数是带格式的**。于是正确分里「泄漏」出格式信号，把格式率从 0.5 也推到了 1.0。
（注：这是与数据一致的推断；严格验证可再做一个「正确分改用严格解析」的对照，但已超出本次作业范围。）

这是本次实验**最有价值的结论**：「RL 只优化被奖励的行为」是一条**理想化**规律，只有被奖励的行为彼此
**独立**时才成立；一旦行为耦合，奖励就会「串味」。课程参考的 Qwen2-0.5B 格式率基线≈0（格式行为在训练前
基本不存在），而本实验的 Qwen2.5 格式率基线≈0.5 且与正确性耦合——**基线模型的选择决定了消融实验能观察到
什么现象**。

### 6.3 信号竞争（w=1.0 拖慢正确率）只观察到弱证据

w=1.0 的最终正确分（0.756）略低于 w=0（0.769）/ w=0.2（0.781），L3 正确率 0.92 也略低于 0.94。
趋势方向与「格式与正确同权时争夺梯度」的预期一致，但幅度（~2pp）在 50 题评估的噪声范围（±~7pp）内，
**不能下强结论**。这是 200 步短训练 + 样本量有限的正常现象。

### 6.4 一句话总结

GRPO 在 Qwen2.5-0.5B 上显著提升算术能力（最难 L6 +18pp）并泛化到未训练难度；而「格式分权重」消融
揭示了一个比预期更深的机制：**奖励之间的耦合**——正确分会泄漏格式信号，说明奖励塑形必须考虑行为在
基座模型里的相关性，而不能假设各奖励分量正交。
