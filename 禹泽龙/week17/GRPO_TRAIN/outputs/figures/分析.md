三张图对应 plot_curves 里的三个子图：

图 1：Reward Components（奖励分量的组均值）

Y 轴：reward 值（0 ~ 1.2）
X 轴：训练 step

实线  reward_correct/mean   — 正确分（宽松解析）

正确分从 ~0.77 爬升到 ~0.94，然后高位震荡
格式分从 ~0.09 快速上升到 0.20 天花板（100% 格式率）
格式分先到顶，正确分后爬坡 → 这是 ARCHITECTURE.md §4.3 说的"典型 RL 动态"，格式是简单信号先收敛


图 2：frac_reward_zero_std（退化组比例）

Y 轴：0 ~ 1（0 = 全有方差，1 = 全退化）
X 轴：训练 step

初期 0 → 模型在训练集上组内多样性大
后期涨到 0.9 → 90% 的组变成全对或全错，advantage ≈ 0，梯度信号枯竭
如果做 LoRA 对比，LoRA 的曲线应该比全量更高（ARCHITECTURE.md 提到 LoRA 退化更严重，0.8~0.95）


图 3：Policy Entropy（策略熵）

Y 轴：entropy（越高 = 输出越多样，越低 = 输出越确定）
X 轴：训练 step

从 ~0.24 降到 ~0.017 → 策略从"多路径探索"收敛为"几乎确定性"
LoRA 的熵应该比全量更低（ARCHITECTURE.md 提到 LoRA 熵 0.57 → 0.02，而全量是 0.57 → 0.10）
